## ⚙️ How It Works  

### 1. Input the Target Website  
Using the Streamlit UI, provide the URL of the webpage from which data needs to be extracted.  

### 2. Configure Extraction Settings  
Customize scraping logic by defining HTML elements and tags to capture. **NEW:** Save these configurations for reusability!  

### 3. Fetch Data  
Hit "Run" to initiate real-time scraping. Extracted data will be displayed in a beautifully formatted table.  

### 4. Export Results  
Export the output to a CSV file for use in data analysis workflows or business reports.  

### 5. Save & Load Configurations  
Save configurations to a file and reload them instantly for recurring scraping tasks, eliminating repetitive setup.

## 🚀 Getting Started  
1. Clone this repository:  
   ```bash  
   git clone https://github.com/EF361/my_crawler.git  
   cd my_crawler  
   ```  
2. Install dependencies:  
   ```bash  
   pip install -r requirements.txt  
   ```  
3. Launch the Streamlit app:  
   ```bash  
   streamlit run app.py  
   ```  

4. Begin scraping and leverage saved configurations for repetitive tasks!
